# Herdsman

Herdsman coordinates assignments between owners and managed Agents.

## Language

**Assistant response**:
A visible answer produced by an Agent during an assignment. An assignment may contain several assistant responses, including partial answers and later revisions.

**Assignment result**:
The terminal execution outcome delivered to an assignment's owner. A completed assignment result contains the selected final eligible assistant response, not necessarily every response produced during the assignment.

**Execution completion**:
An Agent execution ending with a completed runtime outcome and a selected non-empty visible response. Execution completion does not establish that the requested deliverable is complete or correct.
_Avoid_: Accepted work, verified success

**Owner acceptance**:
The owner's judgment that delivered work satisfies the assignment's requirements. Owner acceptance is distinct from execution completion.
